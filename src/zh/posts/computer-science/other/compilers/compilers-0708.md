## 词法分析

### 正则表达式 (regular expression)

 - 运算符: 

| 运算符 | 含义 | 例子 |
|---|---|---|
| `\|` | 选择 / 或 | `(a\|b)` 表示 a 或 b |
| 连接 | 前后连续出现 | `ab` 表示先 a 后 b |
| `*` | 闭包，重复 0 次或多次 | `a*` |
| `+` | 正闭包，重复 1 次或多次 | `a+` |
| `?` | 可选，出现 0 次或 1 次 | `a?` |
| `()` | 分组 | `(a&#124;b)*` |
| `ε` | 空串 | 长度为 0 的字符串 |

### 有限自动机(NFA与DFA)

 - 概念：NFA是一个输入串对应 0、1、或多个转移状态， DFA是输入串和转移状态是1对1关系的。 
 - 计算: NFA转DFA, 或直接画DFA.
   - 子集构造法: 
     - 新的DFA结点(子集): 任意输入对应DFA的一个结点和NFA的一个结点集。先把初态作为一个新结点，然后枚举初态走每一条边(和NFA对应的集合，如果对应NFA状态是一样的，就合并为一个结点)。
     - 然后从新的点开始枚举边，直到不出现新的结点(子集)
     - 加点的同时把边连上，就是一个状态输入什么变到下一个结点。
     - `move(I, a)`: 从状态集合 I 中任意一个状态出发，读入 a 后能到达哪些状态。
     - `ε-closure(I)`: 从状态集合 I 出发，不读任何输入，只沿 ε 边能到达的所有状态，加上自己。
   - 最简DFA:
     - 多余状态: 从开始状态出发，怎么走都走不到的状态，叫多余状态。
     - 等价状态: 从 p 和 q 出发，面对任何输入串，最终接受 / 不接受的结果都一样。 
     - 消除多余状态和等价状态

:::details 

GPT_子集构造法: 
```text
1. 求初态的 ε-closure，作为 DFA 的初态。
2. 对每个 DFA 状态 I 和每个输入符号 a，计算：
   ε-closure(move(I, a))
3. 如果得到新的状态集合，就加入 DFA 状态集。
4. 重复第 2、3 步，直到不再出现新的状态集合。
5. 凡是包含 NFA 终态的 DFA 状态，都是 DFA 终态。
```

:::


:::note 提问_GPT
词法分析的任务是把源程序的字符流切分成一个个单词符号，也叫 Token。常见 Token 包括关键字、标识符、常数、运算符、界符等。词法分析器通常输出单词符号序列，每个单词可以表示为二元组 <单词种别, 单词属性值>。词法分析程序常独立出来，作为语法分析器调用的子程序，这样可以降低编译程序复杂度，便于模块化和维护。

正规式、NFA、DFA 常用于描述和识别单词符号。正规式描述一类字符串集合；NFA 和 DFA 是识别字符串的自动机。DFA 的特点是：每个状态对每个输入符号至多有一个确定的下一状态，且没有 ε 转移。NFA 则允许一个状态对同一输入符号有多个转移，也可以有 ε 转移。

## 语法分析

 - LL:
```text
L：Left-to-right，从左到右扫描输入串
L：Leftmost derivation，最左推导
1：向前看 1 个输入符号
```

 - LR:
```text
L：Left-to-right，从左到右扫描输入串
R：Rightmost derivation in reverse，最右推导的逆过程
1：向前看 1 个输入符号
```

 - [编译原理 - 自顶向下的语法分析](compilers-syntax-analysis_to_bottom.md)
   - LL1
     - FIRST(α)：α 能推出的串的开头可能是什么终结符。
     - FOLLOW(A)：在某个句型中，非终结符 A 后面可能紧跟什么终结符。
     - SELECT(A → α)：当前输入符号是什么时，应该选择产生式 A → α。
     - 预测分析表:非终结符 + 当前输入符号 → 使用哪条产生式
        ```text
        行：非终结符
        列：终结符和 #
        表项：产生式
        ```
     - LL1的判断条件: 同一个非终结符的不同候选式，它们的 SELECT 集是否两两不相交。
     - 消除左递归和提取左公因子: 一些非LL1文法可通过这两种方法转化为LL1，但是并不是使用了这两种方法就一定是LL1.还是需要根据上一条LL1的判断条件进行判定。

**文法**用来描述语言中合法句子的结构。一个文法通常包含终结符、非终结符、开始符号和产生式。终结符是最终出现在句子中的符号，例如 `a、b、+、*、i`；非终结符表示语法成分，例如 `S、A、E、T、F`。推导是从开始符号出发，使用产生式一步步替换非终结符，直到得到终结符串。语法分析的本质就是判断一个输入串是否能由文法推导出来，或者反过来是否能归约成开始符号。

几个符号要记住：

```text
⇒    一步推导
⇒*   0 步或多步推导
⇒+   1 步或多步推导
```

如果一个串中还含有非终结符，它叫**句型**；如果只含终结符，它叫**句子**。

4. 什么是句型？什么是句子？
