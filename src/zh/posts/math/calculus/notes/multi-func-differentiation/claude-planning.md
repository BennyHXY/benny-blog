## 知识脉络总览

### 第一讲 · 多元函数的极限与连续
- [ ] 多元函数的定义、定义域
- [ ] 二元函数极限的定义（与一元的本质区别：无穷多条路径）
- [ ] **证明极限不存在**：找两条路径得不同值
- [ ] **证明极限存在**：夹逼法 / 极坐标换元法 / 换元化为一元极限
- [ ] 连续的定义
- [ ] 连续函数的性质（有界性、最值定理、介值定理）

> ✅ 已完成练习：$\dfrac{x^2y}{x^4+y^2}$（极限不存在）、$\dfrac{x^2+y^2}{\sqrt{x^2+y^2+1}-1}$（极限为2）

### 第二讲 · 偏导数
- [ ] 偏导数的定义（对一个变量求导，其余变量视为常数）
- [ ] 偏导数的计算
- [ ] 高阶偏导数（二阶偏导、混合偏导）
- [ ] **混合偏导相等的条件**：$f_{xy} = f_{yx}$（连续时成立）
- [ ] 偏导数存在 vs 连续的关系（偏导存在 ≠ 连续）

---

### 第三讲 · 全微分
- [ ] 全微分的定义：$dz = f_x\,dx + f_y\,dy$
- [ ] 可微的充分条件（偏导连续 ⟹ 可微）
- [ ] **四个概念的关系**（重难点）：
  ```
  可微 ⟹ 偏导存在
  可微 ⟹ 连续
  连续 ⟹ 偏导存在  ✗（不成立）
  偏导存在 ⟹ 可微  ✗（不成立）
  偏导存在 ⟹ 连续  ✗（不成立）
  ```
- [ ] 全微分在近似计算中的应用

- [ ] 链式法则：树形图辅助理解
- [ ] 复合函数的偏导数计算
- [ ] 全导数公式

### 第五讲 · 隐函数求导
- [ ] 一个方程 $F(x,y)=0$ 确定 $y=f(x)$：$\dfrac{dy}{dx} = -\dfrac{F_x}{F_y}$
- [ ] 一个方程 $F(x,y,z)=0$ 确定 $z=f(x,y)$：$\dfrac{\partial z}{\partial x} = -\dfrac{F_x}{F_z}$
- [ ] 方程组确定的隐函数（用行列式法）
- [ ] 隐函数存在定理（了解条件即可）

---

### 第六讲 · 多元函数的极值 ⭐ 重难点
- [ ] 无条件极值：极值的必要条件（驻点）、充分条件（Hessian 判别法）
  - $A = f_{xx},\ B = f_{xy},\ C = f_{yy}$
  - $AC - B^2 > 0$ 时：$A<0$ 极大，$A>0$ 极小
  - $AC - B^2 < 0$ 时：鞍点
  - $AC - B^2 = 0$ 时：需进一步讨论
- [ ] 最值问题（有界闭区域上的最大最小值）
- [ ] **条件极值：拉格朗日乘数法** $\nabla f = \lambda \nabla g$

---

- [ ] 梯度的定义：$\nabla f = (f_x, f_y)$
- [ ] 梯度方向 = 函数增长最快的方向
- [ ] 梯度与方向导数的关系

- **全微分** → 数值计算中的误差分析
