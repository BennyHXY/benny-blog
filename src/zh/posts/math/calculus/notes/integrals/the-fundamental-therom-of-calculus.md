# 数学 - 微积分基本定理

## 微积分基本定理(第一部分)

- 微积分基本定理(第一部分) -> ==变上限积分求导==

$$
\boxed{
\begin{aligned}
&\textbf{微积分基本定理 (第一部分) }
\text{如果 } f \text{ 是 } [a,b] \text{ 上的连续函数，并且定义函数 } g \text{ 为} \\[6pt]
&\qquad g(x) = \int_{a}^{x} f(t)\,\mathrm{d}t , a \leq x \leq b, \\[6pt]
&\text{那么 } g \text{ 在 } [a,b] \text{ 上连续，在 } (a,b) \text{ 上可微，并且 } g'(x) = f(x) .
\end{aligned}
}
$$

## 微积分基本定理(第二部分)
- 微积分基本定理(第二部分) -> ==牛顿-莱布尼兹公式==
$$
\boxed{
\begin{aligned}
&\textbf{微积分基本定理 (第二部分) }
\text{如果 } f \text{ 在 } [a,b] \text{ 上连续，那么 }  \\[6pt]
&\qquad \int_{a}^{b}f(x)\mathrm{d}x = F(b) - F(a)   \\[6pt]
&\text{其中} F \text{ 是 } f \text{ 的任意原函数，即 } F' = f .
\end{aligned}
}
$$
